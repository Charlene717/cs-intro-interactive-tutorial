CHAPTER 2 / 16

資料表示法

電腦的世界只有 0 與 1。本章教你如何用二進位表達整數、實數、文字與多媒體，並理解 IEEE 754 浮點數的精度陷阱。

A computer sees only 0s and 1s. This chapter shows how to encode integers, reals, text, and media in binary — and reveals the precision traps of IEEE 754.

概覽

為什麼計算機只認得 0 與 1？

因為電子元件最容易、最可靠地表達兩種狀態：「高電壓 / 低電壓」、「導通 / 截止」、「磁化 N / S」、「光點 反射 / 不反射」。將兩種狀態指定為 1 和 0，就得到一個 bit (binary digit)。1 個 bit = 1 個是非題的答案；8 個 bit = 1 個 byte，能表達 0–255 共 256 種狀態。

所有更高層次的資料——整數、小數、文字、圖片、影片、AI 模型權重——都是「許多個 bit 的不同詮釋」。

Because electronic devices most easily and reliably represent two states: high/low voltage, on/off, magnetized N/S, light reflected/not. Assigning these to 1 and 0 yields a bit (binary digit). One bit = answer to one yes/no question; 8 bits = 1 byte, encoding 256 values (0–255).

All higher-level data — integers, decimals, text, images, video, AI weights — are simply different interpretations of bit patterns.

💡
核心觀念：位元組裡的二進位「沒有自帶意義」。同一個 byte 01000001 可以被解讀為整數 65、字元 'A'、或紅綠藍三色中的某個分量——取決於程式上下文。 Core idea: Bits in a byte have no inherent meaning. The byte 01000001 can be interpreted as integer 65, the letter 'A', or a color channel — depending on the program's context.
進位制

一、進位系統

進位制是「以多少種符號表達數字」的規則。日常使用的十進位有 10 個符號 (0–9)，計算機用的二進位有 2 個 (0, 1)，工程師常用的十六進位有 16 個 (0–9, A–F)。

A number system defines how many symbols are used to write numbers. Everyday decimal uses 10 symbols (0–9); computers use binary (0, 1); engineers often use hexadecimal (0–9, A–F).

負數與補數

三、負數表示與二補數

整數需要表示負數。最流行的方案是 二補數 (two's complement)，因為它讓加法器同時處理正負，硬體最簡單。

二補數規則：① 取絕對值的二進位；② 全部位元反轉 (0↔1)；③ 加 1。

範例 (8 bit)： +5 = 0000 0101，所以 −5 = 1111 1011（反轉得 1111 1010，再加 1）。最左邊一位為「符號位」：0 正、1 負。

To encode negatives, the most common scheme is two's complement: it lets one adder handle both signs in hardware.

Rule: (1) take the absolute value in binary; (2) flip every bit; (3) add 1.

Example (8 bit): +5 = 0000 0101, so −5 = 1111 1011 (flip → 1111 1010, +1). The leftmost bit is the sign bit: 0 = positive, 1 = negative.

🚨
整數溢位 (Integer Overflow)：32-bit 有號整數的最大值是 2,147,483,647。再加 1 會變成 −2,147,483,648——這正是 1996 年阿麗亞娜 5 號火箭爆炸的根本原因（64-bit 浮點數轉 16-bit 整數溢位）。
Integer overflow: A 32-bit signed int maxes at 2,147,483,647. Adding 1 wraps to −2,147,483,648 — the root cause of the 1996 Ariane 5 rocket explosion (a 64-bit float converted to 16-bit int overflowed).
IEEE 754 浮點數

四、IEEE 754 浮點數

要在電腦中表達「3.14159」這種實數，使用 IEEE 754 標準（1985 制定，2008/2019 修訂）。它將數字拆成三部分：

(−1)s × 1.M × 2(E − bias)

  • s（符號位 sign）：1 bit，0 正 1 負
  • E（指數 exponent）：8 bit (float32) 或 11 bit (float64)，需減 bias (127 或 1023)
  • M（尾數 mantissa/significand）：23 bit (float32) 或 52 bit (float64)，省略前面的隱含 1

For real numbers like 3.14159, computers use the IEEE 754 standard (1985, revised 2008/2019). Each number has three parts:

(−1)s × 1.M × 2(E − bias)

  • s (sign): 1 bit, 0 positive / 1 negative
  • E (exponent): 8 bits (float32) or 11 bits (float64), with bias 127 or 1023
  • M (mantissa): 23 bits (float32) or 52 bits (float64), with implicit leading 1

🚨
經典陷阱：在 Python 試試 0.1 + 0.2，結果是 0.30000000000000004，不等於 0.3！因為 0.1 在二進位中是無窮迴圈小數（類似 1/3 在十進位）。金融計算絕對不要用浮點數，要用 decimal.Decimal 或整數（以「分」為單位）。
Classic gotcha: Try 0.1 + 0.2 in Python — you get 0.30000000000000004, not 0.3. Because 0.1 is an infinite repeating fraction in binary (like 1/3 in decimal). Never use floats for money — use decimal.Decimal or integers (in cents).
文字編碼

五、文字編碼

ASCII (1963)

7 bit 編碼，表達 128 個英文字母、數字、標點與控制字元。'A' = 65、'a' = 97、'0' = 48。優點簡單；缺點不支援其他語言。

7-bit encoding for 128 characters: English letters, digits, punctuation, control codes. 'A' = 65, 'a' = 97, '0' = 48. Simple but English-only.

Big5 / GB2312 / Shift-JIS

1980 年代各國各自發展中文/日文編碼。同一個 byte 在不同編碼下意義不同 → 出現「亂碼 / mojibake」災難。

In the 1980s, each region (zh-TW Big5, zh-CN GB2312, Japan Shift-JIS) defined its own encoding. Same bytes meant different things → the "mojibake" disaster.

Unicode (1991)

給世界上每個字元一個唯一的「碼點 (code point)」，例如 U+4E2D 代表「中」。目前已收錄 14 萬多個字元（含 emoji 😀）。但 Unicode 只是「身份證」，不是儲存格式。

Assigns every character in the world a unique code point, e.g., U+4E2D = "中". Now includes 140,000+ characters (and emoji 😀). But Unicode is just the "ID number" — not a storage format.

UTF-8 (1992) ⭐

把 Unicode 碼點變成 1–4 個 byte：英文 1 byte（與 ASCII 完全相容）、中文 3 byte、emoji 4 byte。今天 98%+ 網頁使用 UTF-8，是事實上的網路標準。

Encodes Unicode as 1–4 bytes: ASCII 1 byte (backward-compatible), Chinese 3 bytes, emoji 4 bytes. 98%+ of web pages use UTF-8 today — the de facto internet standard.

六、選用合適的資料型別

🌳 資料型別決策樹

Q1:
儲存「金額」嗎？→ 是 → 用 整數（分為單位）或 decimal.Decimal，絕不用 float。
Q2:
儲存「科學測量值」？→ 是 → float64 (double)，精度約 15 位有效數字。
Q3:
訓練「AI 模型」？→ 是 → 訓練用 BF16 / FP16，推論用 FP8 或 INT8 量化。
Q4:
儲存「文字」？→ 是 → 一律 UTF-8。資料庫 charset 設 utf8mb4（MySQL）。
Q5:
儲存「布林 (T/F)」？→ 是 → 1 bit 就夠，但記憶體仍按 byte 對齊；若要省，用 bitmask。
Q1:
Storing money? → Yes → Use integer cents or decimal.Decimal; never float.
Q2:
Scientific measurements? → Yes → float64, ~15 significant digits.
Q3:
Training AI models? → Yes → Train in BF16/FP16, infer in FP8 or INT8 quantized.
Q4:
Storing text? → Yes → Always UTF-8. DB charset = utf8mb4 (MySQL).
Q5:
Storing booleans? → Yes → 1 bit suffices but memory aligns to bytes; pack with bitmasks if it matters.

七、動手試

# 進位轉換 / Base conversion
print(bin(42))    # '0b101010'
print(hex(255))   # '0xff'
print(int('1010', 2))   # 10  (binary string → int)
print(int('FF', 16))     # 255 (hex string → int)

# 浮點數精度陷阱 / Floating-point gotcha
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False !
import math
print(math.isclose(0.1+0.2, 0.3))     # True (correct way)

# 金額用 Decimal / Money with Decimal
from decimal import Decimal
print(Decimal('0.1') + Decimal('0.2'))   # 0.3 (exact!)

# 文字編碼 / Text encoding
s = "中文 Hello 🌏"
print(s.encode('utf-8'))      # b'\xe4\xb8\xad\xe6\x96\x87 Hello \xf0\x9f\x8c\x8f'
print(len(s.encode('utf-8')))   # 14 bytes (中 3 + 文 3 + ' Hello ' 7 + 🌏 4 − ' ' miscount? recheck)

# 二補數演示 / Two's complement demo
n = -5
print(format(n & 0xFF, '08b'))  # '11111011'  (8-bit two's complement)
// 十進位轉二進位（除 2 取餘法）/ Decimal → binary by repeated division
function DecToBin(n):
    if n == 0: return "0"
    let bits = ""
    while n > 0:
        bits = (n mod 2) + bits      // 將餘數放最前面
        n = n ÷ 2                    // 整數除法
    return bits

// 二補數（將正數轉為其 n-bit 負數）/ Two's complement: positive → n-bit negative
function TwosComp(value, n_bits):
    let mask = 2^n_bits − 1
    return ((NOT value) + 1) AND mask
