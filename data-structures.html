資料結構

演算法是邏輯；資料結構是容器——兩者一體兩面。選對容器，演算法的複雜度自然下降。

Algorithms are the logic; data structures are the containers — two faces of the same coin. Pick the right container and complexity drops on its own.

概覽

為什麼資料結構重要？

同一個搜尋任務，用未排序陣列要 O(n)、排序陣列加二分搜尋要 O(log n)、Hash Table 卻只要 O(1)。資料結構決定了你的演算法能跑多快。

Linus Torvalds 曾說：「Bad programmers worry about the code. Good programmers worry about data structures and their relationships.」這也是面試的高頻考點。

The same lookup is O(n) in an unsorted array, O(log n) in a sorted array with binary search, and O(1) in a hash table. Data structures dictate how fast your algorithm can run.

Linus Torvalds: "Bad programmers worry about the code. Good programmers worry about data structures and their relationships." Also the most-tested interview topic.

💡
核心觀念：每種資料結構都是一組「時空 trade-off」。Hash 快但耗記憶體；Linked List 省記憶體但慢；Array 中庸但插入差。沒有萬能解。 Core idea: Every data structure is a time-space trade-off. Hashes are fast but memory-hungry; linked lists are slim but slow; arrays are middle-of-the-road but slow to insert. No silver bullet.
線性結構

一、線性資料結構

📦 Array

連續記憶體區塊。存取 O(1)，但插入/刪除中間元素需移動其他元素 O(n)。Python 的 list、C 的陣列、Java 的 ArrayList 屬此類。

Contiguous memory. Random access O(1); inserting/deleting in the middle is O(n) because elements must shift. Python list, C arrays, Java ArrayList are arrays.

🔗 Linked List

每個 node 透過指標指向下一個 node。插入/刪除 O(1)，但隨機存取 O(n)。雙向、循環、跳表等變體。

Each node points to the next. Insert/delete O(1); random access is O(n). Variants: doubly-linked, circular, skip list.

📚 Stack (LIFO)

「後進先出」（Last In First Out）。瀏覽器返回、函式呼叫、撤銷 (undo) 全靠 stack。操作：push、pop、peek，全為 O(1)。

Last In, First Out. Browser back, function calls, undo — all stacks. Push, pop, peek are O(1).

🎫 Queue (FIFO)

「先進先出」。任務排程、訊息佇列、BFS 都用 queue。雙端佇列 (deque) 可雙頭操作，Python 的 collections.deque 是優選。

First In, First Out. Task scheduling, message queues, BFS use queues. A deque allows ops at both ends; Python's collections.deque is preferred.

Hash Table

三、Hash Table

Hash Table 由 hash function 把 key 對應到陣列索引。理想情況下，查找、插入、刪除都是 O(1)。Python 的 dict、JavaScript 的 Object / Map、Java 的 HashMap 都基於 hash。

碰撞 (collision)：兩個 key 算出同一個索引時的處理方式：

  • Chaining：每個 bucket 是一個 linked list。Python、Java 採用。
  • Open Addressing：碰撞時跳到下一個空 bucket。CPU cache 友善，但需要小心 load factor。

A hash table uses a hash function to map keys to array indices. Ideally lookup/insert/delete are O(1). Python dict, JS Object/Map, Java HashMap all use hashes.

Collision handling — when two keys hash to the same bucket:

  • Chaining: each bucket is a linked list. Used by Python and Java.
  • Open Addressing: probe to the next empty bucket. Cache-friendly but watch the load factor.

進階資料結構

五、進階資料結構

🌸 Bloom Filter

機率性結構：「絕對不存在」或「可能存在」。極省記憶體，常用於 CDN、爬蟲去重、資料庫快取預判。

Probabilistic set: "definitely not" or "maybe." Tiny memory; used for CDN caches, crawler dedup, DB cache prefilter.

🪜 Skip List

多層 linked list，期望 O(log n) 查找。Redis 的 sorted set (zset) 與某些資料庫索引用此結構。

Multi-level linked list with expected O(log n) lookup. Used by Redis sorted sets and some DB indexes.

🌲 LSM-Tree

Log-Structured Merge Tree。寫入快、適合 SSD，LevelDB、RocksDB、Cassandra、ScyllaDB 都用。

Log-Structured Merge Tree. Write-optimized, SSD-friendly; powers LevelDB, RocksDB, Cassandra, ScyllaDB.

Q5:
需要範圍查詢 / 排序順序遍歷？→ 是 → BST / Skip List / B-Tree (DB 索引)。

處理關聯/網路？→ Graph + Adjacency List，搭配 BFS / DFS / Dijkstra。
Q1:
Fast key→value lookup? → Yes → Hash Table, avg O(1). Need sorted iteration too → use a tree-based map.
Q2:
Frequent push/pop at one end? → Yes → Stack (LIFO); both ends → deque.
Q3:
FIFO (task scheduling, BFS)? → Yes → Queue or deque.
Q4:
Always need max/min? → Yes → Heap / Priority Queue: heapq, Java PriorityQueue.

Range queries / sorted scan? → Yes → BST / Skip List / B-Tree (DB indexes).

# 2. 自製 Binary Search Tree
class Node:
    def __init__(self, key):
        self.key, self.left, self.right = key, None, None

class BST:
    def __init__(self):
        self.root = None
    def insert(self, key):
        self.root = self._ins(self.root, key)
    def _ins(self, node, key):
        if node is None: return Node(key)
        if key < node.key: node.left  = self._ins(node.left, key)
        elif key > node.key: node.right = self._ins(node.right, key)
        return node
    def contains(self, key):
        n = self.root
        while n:
            if key == n.key: return True
            n = n.left if key < n.key else n.right
        return False

t = BST()
for v in [5, 3, 7, 1, 4]: t.insert(v)
print(t.contains(4))   # True (平均 O(log n))
// BFS：用 queue 走訪圖，找到由 start 出發各點的最短「邊數」
function BFS(graph, start):
    let visited = new Set()
    let queue = new Queue()
    queue.enqueue(start)
    visited.add(start)
    while not queue.empty():
        let node = queue.dequeue()
        visit(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.enqueue(neighbor)
