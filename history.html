計算機發展簡史

從算盤、Babbage 分析機到圖靈、von Neumann、ENIAC 與 2026 年量子優勢——理解七十年來計算機如何形塑現代生活。

From abacus and Babbage to Turing, von Neumann, ENIAC, and 2026's quantum advantage — understand how seven decades of computing have shaped modern life.

概覽

為什麼要懂計算機歷史？

每一項你今天使用的技術——從手機、雲端服務到 ChatGPT——都站在數十年累積的概念之上。圖靈機 (1936) 定義了「可計算」的數學邊界，von Neumann 架構 (1945) 至今仍是 99% 計算機的設計藍圖，摩爾定律 (1965) 推動了半導體產業的指數成長。

理解歷史能幫你：① 避免重新發明輪子；② 看清當前技術的限制來自何處；③ 預測下一波典範轉移（如量子運算、神經型態運算）。

Every technology you use today — phones, cloud, ChatGPT — rests on decades of accumulated ideas. The Turing Machine (1936) defined the mathematical boundary of "computable," von Neumann architecture (1945) remains the blueprint for 99% of computers, and Moore's Law (1965) drove exponential semiconductor growth.

Understanding history helps you: (1) avoid reinventing wheels, (2) see where current limits come from, (3) predict the next paradigm shift (quantum, neuromorphic).

💡
核心觀念：計算機 ≠ 電子產品。計算機是「能執行演算法、儲存資料」的任何系統，從機械齒輪、繼電器、真空管、電晶體、積體電路一路演進到今天的量子位元。 Core idea: A computer is not just an electronic device. It is any system that executes algorithms and stores data — from mechanical gears to relays, vacuum tubes, transistors, ICs, and quantum bits.

關鍵人物

二、十位塑造計算機科學的人

🧮 Charles Babbage (1791–1871)

設計「分析機 (Analytical Engine)」——史上第一台可程式化機械計算機，雖未完工，但定義了 CPU + 記憶體 + I/O 的架構雛形。

Designed the Analytical Engine — the first programmable mechanical computer. Never completed, but laid out the CPU + memory + I/O architecture.

🌹 Ada Lovelace (1815–1852)

為 Babbage 分析機寫出第一個「程式」，被譽為史上第一位程式設計師。預言計算機能處理「非數字」的符號。

Wrote the first "program" for Babbage's machine. Considered the first computer programmer. Foresaw that computers could manipulate non-numeric symbols.

🧠 Alan Turing (1912–1954)

提出 圖靈機 與 圖靈測試。二戰期間破解 Enigma 密碼。所有現代計算機在數學上都等價於圖靈機。

Defined the Turing machine and Turing test. Cracked the Enigma cipher in WWII. All modern computers are mathematically equivalent to a Turing machine.

📡 Claude Shannon (1916–2001)

資訊理論之父。1948 年定義「位元 (bit)」與通道容量公式 C = B·log₂(1+S/N)，奠定了所有數位通訊的基礎。

Father of information theory. Defined the "bit" in 1948 and the channel capacity formula C = B·log₂(1+S/N), foundational to all digital communications.

🏛️ John von Neumann (1903–1957)

1945 年提出「儲存程式概念 (stored-program)」——程式與資料儲存在同一記憶體中。所有現代 CPU 都基於 von Neumann 架構。

Proposed the stored-program concept in 1945 — programs and data live in the same memory. All modern CPUs use von Neumann architecture.

🔋 Gordon Moore (1929–2023)

Intel 創辦人之一。1965 年提出「摩爾定律」：IC 上的電晶體數每 18–24 個月增為兩倍。已維持 60 年，2020 年代開始放緩。

Intel co-founder. In 1965 stated Moore's Law: transistors per IC double every 18–24 months. Held for 60 years, slowing in the 2020s.

👩‍💻 Grace Hopper (1906–1992)

美國海軍少將。設計第一個編譯器 (A-0, 1952)、共同創造 COBOL；命名了「bug」與「debug」術語。

U.S. Navy Rear Admiral. Built the first compiler (A-0, 1952); co-created COBOL. Coined the terms "bug" and "debug."

🐧 Linus Torvalds (1969–)

21 歲時開發 Linux kernel (1991) 與後來的 Git (2005)。Linux 驅動了今天 90%+ 的雲端、超級電腦與 Android 裝置。

At 21, created Linux kernel (1991) and later Git (2005). Linux powers 90%+ of today's cloud, supercomputers, and Android devices.

🌐 Tim Berners-Lee (1955–)

1989 年於 CERN 發明 World Wide Web、HTTP 與 HTML。1990 年寫出世界第一個瀏覽器與網頁伺服器。

Invented the World Wide Web, HTTP, and HTML at CERN in 1989. Built the first browser and web server in 1990.

1936
Turing's computability paper → defined what is "computable" and the math foundation of CS.
1945
von Neumann report → unified program + data storage; blueprint for 99% of modern CPUs.
1947
Bell Labs invents the transistor → replaces vacuum tubes; launches the semiconductor era. Inventors win the 1956 Nobel Prize.

⚠️
2026 觀察：摩爾定律的「每 18 個月翻倍」已減速到約 30 個月。新的成長動力來自：① 3D 堆疊封裝 (Intel Foveros、TSMC SoIC)；② chiplet 架構；③ 專用 AI 加速器（GPU/NPU/TPU）；④ 後 CMOS 技術（量子、光子、神經型態）。
2026 perspective: Moore's classic "18-month doubling" has slowed to ~30 months. New growth drivers: (1) 3D-stacked packaging (Intel Foveros, TSMC SoIC); (2) chiplet architectures; (3) specialized AI accelerators (GPUs/NPUs/TPUs); (4) post-CMOS (quantum, photonic, neuromorphic).
程式碼

五、用 Python 計算摩爾定律

# 摩爾定律：電晶體數每 18 個月翻倍 / Moore's law: transistors double every 18 months
def moore_predict(start_year, start_count, target_year, doubling_months=18):
    months = (target_year - start_year) * 12
    doublings = months / doubling_months
    return start_count * (2 ** doublings)

# Intel 4004 (1971) 有 2,300 顆電晶體 / Intel 4004 had 2,300 transistors in 1971
predicted_2024 = moore_predict(1971, 2300, 2024)
print(f"Predicted 2024: {predicted_2024:,.0f}")
# 預測：~5.7 兆顆，但實際 Apple M4 Max ~280 億 → 摩爾定律已減速
# Prediction: ~5.7 trillion, but Apple M4 Max has ~28 billion → Moore's slowing
// 演算法：估算指定年份的電晶體數 / Algorithm: estimate transistor count at year Y
function MoorePredict(start_year, start_count, target_year, doubling_months):
    let months = (target_year - start_year) × 12
    let doublings = months ÷ doubling_months
    return start_count × 2^doublings

// 主程式 / Main
let result = MoorePredict(1971, 2300, 2024, 18)
print(result)
