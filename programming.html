CHAPTER 9 / 16

程式設計入門

程式語言是「人類意圖」與「機器指令」之間的橋樑——從 C 的低階控制、Python 的可讀性、到 Rust 的安全保證，每種語言都是一套取捨。

A programming language is the bridge between human intent and machine instructions — C for low-level control, Python for readability, Rust for safety. Every language is a set of trade-offs.

概覽

什麼是程式語言？

CPU 只看得懂 0 與 1 組成的「機器碼」，但人類大腦無法直接寫機器碼。程式語言提供一套有結構、可閱讀的語法，讓人寫出意圖，再由編譯器 (compiler) 或直譯器 (interpreter) 翻譯成 CPU 能執行的指令。

2026 年全世界有超過 700 種正在使用的程式語言，但「主流」大約 20 種。選對語言可以決定一個專案的成敗。

A CPU only understands binary machine code, but humans cannot write that directly. A programming language gives us readable syntax to express intent, which a compiler or interpreter translates into machine instructions.

As of 2026, 700+ programming languages are in active use, with ~20 mainstream ones. Choosing the right one can make or break a project.

💡
核心觀念：不存在「最好」的語言，只有「最合適」的語言。Web 前端用 JavaScript / TypeScript、AI 用 Python、系統程式用 Rust / C++、行動 App 用 Swift / Kotlin——每種語言都針對某個領域最佳化。 Core idea: There is no "best" language, only the "right" one. JS/TS for web front-end, Python for AI, Rust/C++ for systems, Swift/Kotlin for mobile — each is optimized for a domain.

語言世代

二、五代程式語言

1GL — Machine Code

純 0/1 二進位指令，直接餵給 CPU。1940 年代靠打孔卡輸入，極端難寫、難 debug。

Raw 0/1 binary fed directly to the CPU. In the 1940s entered via punched cards — nearly impossible to write or debug.

2GL — Assembly

以助憶符號代替二進位（MOV, ADD, JMP）。1 對 1 對應到機器碼，但仍極度依賴 CPU 架構。

Mnemonics replace binary (MOV, ADD, JMP). One-to-one with machine code, still very CPU-specific.

3GL — High-Level

Fortran (1957)、COBOL、C、Java、Python——一行可以對應數十個機器指令，可在不同 CPU 上 portable。

Fortran (1957), COBOL, C, Java, Python — one line maps to dozens of machine instructions and is portable across CPUs.

4GL — Declarative

SQL、MATLAB、R——「描述想要什麼」而非「怎麼做」。針對特定領域 (database、數值計算) 最佳化。

SQL, MATLAB, R — describe what you want, not how. Optimized for specific domains (DB, numerical computing).

5GL — Logic / AI

Prolog、Mercury，以邏輯規則推導。2026 「prompt engineering」與 LLM-driven coding 也常被視為新一代 5GL。

Prolog, Mercury — solve via logical rules. In 2026, prompt engineering and LLM-driven coding are often viewed as a new 5GL.

程式典範

三、五大程式設計典範

📜 Imperative / Procedural

「一步一步告訴電腦怎麼做」。以變數、指派、迴圈為核心。C、Pascal、Go 偏向此典範。

Tell the computer step-by-step what to do. Centers on variables, assignment, loops. C, Pascal, Go lean here.

🧱 Object-Oriented (OOP)

把資料 (state) 和行為 (method) 包成「物件」。四大支柱：封裝、繼承、多型、抽象。Java、C++、Python、C# 都支援。

Bundle data (state) and behavior (methods) into objects. Four pillars: encapsulation, inheritance, polymorphism, abstraction. Java, C++, Python, C# support OOP.

λ Functional

把計算當作「數學函式」的求值，避免共享狀態與副作用。Haskell、Lisp、Erlang；Python/JS 也吸收許多 FP 特性 (map, filter, reduce)。

Treat computation as evaluation of mathematical functions, avoiding shared state and side effects. Haskell, Lisp, Erlang; Python/JS absorbed many FP features (map, filter, reduce).

🧠 Logic

以「事實」與「規則」描述問題，由系統推導答案。Prolog 是最典型。AI 推理引擎與 Datalog 是現代後繼者。

State facts and rules; the system infers answers. Prolog is the classic. Modern descendants: AI reasoning engines and Datalog.

📋 Declarative

「描述目標」而非「步驟」。SQL (查詢)、HTML/CSS (UI)、Terraform (基礎建設) 都是 declarative。

Describe goals, not steps. SQL (queries), HTML/CSS (UI), Terraform (infrastructure) are all declarative.

🧬 OOP 四大支柱

封裝：state 隱藏在物件內；繼承：子類繼承父類；多型：同名方法在不同類別有不同實作；抽象：用介面隱藏細節。

Encapsulation: state hidden inside objects; Inheritance: subclass extends parent; Polymorphism: same method, different implementations; Abstraction: interfaces hide details.

六、動手寫 Python

# 1. Hello World
print("Hello, World!")

# 2. 變數、控制流、函式 / Variables, control flow, function
def factorial(n: int) -> int:
    """遞迴計算 n! / recursive factorial"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

for i in range(1, 6):
    print(f"{i}! = {factorial(i)}")

# 3. OOP：封裝 + 繼承 + 多型 / Encapsulation + inheritance + polymorphism
class Animal:
    def __init__(self, name: str):
        self.name = name        # 封裝：state
    def speak(self) -> str:
        return "..."

class Dog(Animal):       # 繼承
    def speak(self):       # 多型：覆寫
        return f"{self.name} says Woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says Meow!"

for a in [Dog("Rex"), Cat("Luna")]:
    print(a.speak())   # 多型呼叫同一介面
// 同樣的功能寫成偽碼 / Same logic in pseudocode
PRINT("Hello, World!")

function Factorial(n):
    if n <= 1: return 1
    return n × Factorial(n − 1)

for i from 1 to 5:
    PRINT(i, "! =", Factorial(i))

class Animal:
    field name
    method speak(): return "..."

class Dog extends Animal:
    method speak(): return name + " says Woof!"

class Cat extends Animal:
    method speak(): return name + " says Meow!"

for a in [Dog("Rex"), Cat("Luna")]:
